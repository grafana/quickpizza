# Mobile quickstarts

Tiny single-screen apps that send telemetry to Grafana Frontend Observability using **plain
OpenTelemetry**, with no Grafana SDK or wrapper package. Each one is the smallest correct setup,
made to be copied into your own app.

| Platform | SDK | Guide |
| --- | --- | --- |
| iOS | OpenTelemetry Swift | [ios/README.md](./ios/README.md) |
| Android | OpenTelemetry Android | [android/README.md](./android/README.md) |

They are separate from the QuickPizza demo apps in the parent folder, which show a full app with
more instrumentation.
